# 📚 Library Management System (C# Windows Forms)

This is a desktop-based Library Management System built using C# and Windows Forms (.NET Framework 4.7.2). It allows users to manage library operations such as book issuance, returns, member management, and record-keeping in a simple UI.

---

## 🔧 Features
- Add, update, and delete books
- Issue and return books
- Manage members/students
- Track borrowing history
- Search functionality for books and members

---

## 🛠 Technologies Used
- Programming Language: **C#**
- Framework: **.NET Framework 4.7.2**
- UI: **Windows Forms (WinForms)**
- IDE: **Visual Studio**
- Data Handling: **In-memory / File-based (if no external DB used)**

---

## 📁 Project Structure
```
Library Management System/
├── Form1.cs                # Main form logic
├── Form1.Designer.cs       # UI design code
├── Program.cs              # Entry point of application
├── App.config              # Configuration file
├── Properties/             # App settings and resources
└── Library Management System.sln  # Visual Studio Solution file
```

---

## 🚀 How to Run
1. Open `Library Management System.sln` in **Visual Studio**
2. Make sure **.NET Framework 4.7.2** is installed
3. Click **Start (▶️)** or press **F5** to run the application
